# Arshia_portfolio

سایت پورتفولیو ارشیا امیرآبادی (انیماتور سه‌بعدی و سرپرست موشن‌کپچر).

## ویرایش نمونه‌کارها
همه‌چیز در `works.js` است: دسته‌ها (`CATEGORIES`)، کارها (`WORKS`) و نام‌های نوار متحرک (`CLIENTS`).
برای کار جدید: `media/<id>.jpg` (و اختیاری `media/clip-<id>.mp4`) را اضافه کن و یک خط در `WORKS` بنویس.
`at` ثانیه‌ای است که آن کار در `media/reel.mp4` شروع می‌شود.

## انتشار
Settings ← Pages ← Source: Deploy from a branch ← برنچ را انتخاب کن، پوشه‌ی `/ (root)` ← Save
