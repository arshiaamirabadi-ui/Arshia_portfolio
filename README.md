# Arshia_portfolio

سایت پورتفولیو ارشیا امیرآبادی (انیماتور سه‌بعدی).

## اضافه کردن نمونه‌کار
1. فایل عکس/ویدیو را داخل پوشه `media/` بگذار (ویدیوهای سنگین را روی آپارات/یوتیوب بگذار).
2. در فایل `works.js` یک خط به لیست `WORKS` اضافه کن. راهنمای فیلدها بالای همان فایل است.

## انتشار
Settings ← Pages ← Source: Deploy from a branch ← شاخه را انتخاب کن، پوشه `/ (root)` ← Save
